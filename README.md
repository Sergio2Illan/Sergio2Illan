🎯 **Sobre mí**

Soy un desarrollador con un sólido background en Java y certificación como AEM Sites Developer, lo que me ha dado una base robusta en entornos empresariales. Actualmente, he decidido dar un giro estratégico a mi carrera para **especializarme en el desarrollo de aplicaciones Android**.

Mi enfoque actual es dominar el desarrollo nativo moderno, creando aplicaciones que no solo sean funcionales, sino que ofrezcan una **experiencia de usuario fluida y robusta**, aplicando principios de Clean Architecture y las últimas herramientas recomendadas por Google.

Actualmente estoy perfeccionando mis habilidades con:

- **Kotlin** (Lenguaje principal para Android moderno)
- **Jetpack Compose** (UI declarativa y moderna)
- **Android Architecture Components** (ViewModel, LiveData, Room)
- **Corrutinas y Flow** (Gestión de asincronía y flujos de datos)
- **Consumo de APIs** con Retrofit y serialización con Kotlin Serialization/Gson
- **Inyección de dependencias** con Hilt o Koin
- **Clean Architecture y MVVM** (Patrones de diseño esenciales)
